# SLA and DPA Package Template

Status: counsel and operations approval required before customer signature.

## SLA schedule

- Covered service and production environment: to be named in the order form.
- Availability target: not committed until monitoring source, maintenance exclusions and service-credit approval are recorded.
- Incident severity, acknowledgement and restoration targets: to be approved by the named on-call owner.
- Customer notification channel and status page: external gate.
- RTO/RPO: customer policy values are recorded by the control plane; recovery evidence must be attached before they become commitments.
- Service credits, claim window and exclusive-remedy language: counsel and finance approval required.

## DPA schedule

- Roles: customer as controller/business; TAVONEL role to be confirmed per jurisdiction and processing purpose.
- Processing subject, duration, data categories and data subjects: order-form schedule required.
- Documented instructions and confidentiality: contract schedule required.
- Security measures: map only controls with current evidence from the security questionnaire.
- Subprocessors and change notice: publish and contractually bind the current subprocessor registry.
- Cross-border transfers and supplementary measures: counsel approval required for each selected region.
- Deletion/return, audit assistance, incident notice and data-subject request assistance: runtime procedures and owners required.

Never sign this template as-is. The executable agreement must name the legal TAVONEL entity, registered address, governing law, subprocessors and approved service commitments.
