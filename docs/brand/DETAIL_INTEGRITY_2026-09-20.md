# Source, brand and Workspace detail integrity — 2026-09-20

## Reproduced defects
1. Proof used a fixed 24px dash, not a connection to the selected source region.
2. Evidence reached the region numerically but painted behind the opaque paper; its start was beside metadata, not the claim.
3. The tab screenshot carried the retired symbol. The current SVG was LOCUS, but there was no favicon.ico fallback and its geometry was independently rounded.
4. Compile lifecycle position reserved a large canvas even with no received page or result; a terminal ready job was presented like AI activation.
5. The canvas responded only to window resize, not container layout changes or font readiness.
6. The mobile command button had no accessible name when its text was hidden; long command lists lacked a viewport bound.
7. Invalid nonfinite/out-of-page source coordinates were not rejected by the visual primitive.

## Changes
- Bounded, measured SVG connections from quote/claim to exact source region. Observe image load, fonts, container resize and tab visibility; omit on stacked layouts.
- Original PDFs, raster evidence assets, recorded excerpts and coordinates are unchanged.
- One canonical LOCUS geometry for navigation, share/apple icons and explicit versioned SVG/PNG/ICO tab representations; legacy URLs serve the same symbol.
- A pure Workspace view model separates stored inventory, a running job, received visual payload, a completed candidate and an activated result. A new job cannot use the previous result as its own evidence.
- Missing payload is a compact, visible status explanation, never an empty success canvas. A missing 2D context preserves readable status and data counts.
- Container-aware canvas redraw, wider Workspace content, readable command controls and viewport-bounded keyboard palette.

## Verification scope
New unit and browser regressions cover the reported 31-ready/44-held shape, missing result payloads, activation distinction, real source endpoint geometry, tab re-selection, resize, canvas failure and icon routes.
Full public route and authenticated-fixture surface audits are recorded separately. Fixture session checks do not constitute a real customer login, upload, paid compile or billing transaction.
The customerData and candidatePromotion gates, migrations, locked film bytes and original sources are not changed.

Release is pending exact-head CI, preview review and final production verification at the time of this implementation record.
